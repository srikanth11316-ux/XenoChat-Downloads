# XenoChat Downloads

Official installers for [XenoChat](https://xenochat-kzci.onrender.com).

## Downloads

- **Windows:** [XenoChat-Setup.exe](https://github.com/srikanth11316-ux/XenoChat-Downloads/releases/latest/download/XenoChat-Setup.exe)
- **Android:** [XenoChat.apk](https://github.com/srikanth11316-ux/XenoChat-Downloads/releases/latest/download/XenoChat.apk)

These apps connect to the hosted XenoChat service and require an internet connection. This public repository distributes release binaries only; the XenoChat source code remains private.

### Notes

- The Windows installer is currently unsigned, so Windows may display a SmartScreen warning.
- The Android APK is debug-signed for direct installation/testing and is not a Play Store package.
